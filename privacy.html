Privacy Policy for YoutuRead

YoutuRead ("the Extension") is committed to protecting your privacy. This Privacy Policy explains what information is collected, how it is used, and how it is protected.

1. Information We Collect

YoutuRead may process the following information solely to provide its core functionality:

  • YouTube video URLs
  • Video subtitles or transcripts
  • User-selected AI prompts
  • User settings, such as preferred AI provider
  • API Keys provided by users, including OpenAI, DeepSeek, Gemini, and other providers

2. How We Use Information

The collected information is used only to:

  • Generate AI summaries
  • Convert YouTube videos into readable notes
  • Produce Markdown documents
  • Generate shareable images
  • Remember user preferences

We do not use your data for advertising or user profiling.

3. API Keys

API Keys entered by users are:

  • Stored locally in the browser whenever possible
  • Used only for sending requests to the AI service selected by the user
  • Never sold or shared with third parties

4. Data Sharing

YoutuRead does not sell personal information.

Data is transmitted only when necessary to:

  • OpenAI
  • DeepSeek
  • Google Gemini
  • Other AI providers explicitly selected by the user

These requests are solely for generating AI responses.

5. Data Storage

Most settings are stored locally using Chrome Extension Storage.

YoutuRead does not maintain a database of users or their browsing history.

6. Security

All communications with external AI services use encrypted HTTPS connections.

7. Third-Party Services

YoutuRead interacts with:

  • YouTube
  • OpenAI API
  • DeepSeek API
  • Google Gemini API

Each service is governed by its own privacy policy.

8. Children's Privacy

YoutuRead is not intended for children under 13 years of age.

9. Changes

This Privacy Policy may be updated from time to time.
