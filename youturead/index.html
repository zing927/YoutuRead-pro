INSTALLATION GUIDE

选择一种方式，
几分钟完成安装。

推荐优先通过 Chrome 应用商店安装，可以自动接收后续更新。如果商店暂时无法访问，也可以使用离线安装包。

方式 01推荐

从 Chrome 应用商店安装

  1. 1
    打开 Chrome 应用商店

    点击下方按钮，或在 Chrome 应用商店中搜索“YoutuRead”。

  2. 2
    找到 YoutuRead

    进入插件详情页，确认插件名称和图标后点击「添加至 Chrome」。

  3. 3
    确认添加扩展程序

    在浏览器弹窗中点击「添加扩展程序」，等待安装完成。

  4. 4
    固定到浏览器工具栏

    点击右上角拼图图标，在 YoutuRead 右侧点击图钉，之后就能快速打开。

去 Chrome 应用商店搜索 ↗
方式 02离线安装

使用离线安装包

  1. 1
    获取并解压安装包

    下载 YoutuRead 离线安装包，将 ZIP 文件完整解压到一个固定文件夹。安装后请勿删除或移动该文件夹。

  2. 2
    打开扩展程序页面

    在 Chrome 地址栏输入 chrome://extensions，按回车进入扩展程序管理页。

  3. 3
    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4
    加载已解压的扩展程序

    点击左上角「加载已解压的扩展程序」，选择刚才解压后的文件夹。请选中包含 manifest.json 的那一层。

  5. 5
    完成安装并固定插件

    看到 YoutuRead 卡片且开关已开启即安装成功。点击工具栏拼图图标，将它固定到浏览器。
